## Points à vérifier
- [ ] Lisibilité et clarté du code
- [ ] Respect des conventions et bonnes pratiques
- [ ] Performance et optimisations possibles
- [ ] Sécurité (injections, XSS, CSRF, etc.)
- [ ] Gestion des erreurs et cas limites
- [ ] Couverture de tests
- [ ] Documentation / commentaires

## Format de réponse souhaité
1. **Résumé** : évaluation globale (✅ Bon / ⚠️ À améliorer / ❌ Problèmes critiques)
2. **Points positifs** : ce qui est bien fait
3. **Améliorations suggérées** : avec exemples de code corrigé
4. **Problèmes critiques** : à corriger absolument
