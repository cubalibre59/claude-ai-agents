# Template — Refactoring de code

## Usage
Remplacez les placeholders `{{...}}` et envoyez à votre coding-agent.

---

Refactorise le code suivant en améliorant sa qualité sans changer son comportement.

**Objectifs du refactoring** :
- [ ] Améliorer la lisibilité
- [ ] Réduire la duplication (DRY)
- [ ] Améliorer les performances
- [ ] Moderniser la syntaxe
- [ ] Appliquer les design patterns appropriés
- [ ] Autre : {{précisez}}

**Contraintes** :
{{Ex: garder la compatibilité avec PHP 8.0, ne pas changer l'interface publique, etc.}}

**Code original** :
```
{{collez votre code ici}}
```

## Format de réponse souhaité
1. **Analyse** : problèmes identifiés dans le code original
2. **Code refactorisé** : version améliorée complète
3. **Changements expliqués** : liste des modifications avec justifications
4. **Impact** : amélioration attendue en lisibilité / performance / maintenabilité
