# 📝 Prompts

Collection de prompts réutilisables pour les agents Claude.

## Structure

```
prompts/
├── templates/
│   ├── code-review.md       # Revue de code
│   ├── bug-fix.md           # Correction de bugs
│   ├── documentation.md     # Génération de doc
│   └── refactoring.md       # Refactoring de code
└── README.md
```

## Utilisation
Copiez-collez le contenu d'un template dans votre conversation Claude,
en remplaçant les placeholders `{{...}}` par vos valeurs.

## Contribuer
Ajoutez vos propres templates dans `templates/` et documentez-les ici.
