# ⚛️ React Agent

Agent IA spécialisé pour le développement frontend avec React et son écosystème.

## Rôle
Cet agent est expert en :
- Architecture React (hooks, composants, patterns)
- State Management (Redux Toolkit, Zustand, Jotai, React Query)
- React Router v6+
- Styling (Tailwind CSS, CSS Modules, Styled Components)
- Tests (Vitest, Jest, React Testing Library, Playwright)
- Performances (memo, lazy, Suspense, Server Components)
- Next.js (App Router, SSR, SSG, ISR)

## Pré-requis
- Node.js 18+
- React 18+ / 19+
- TypeScript 5+

## Utilisation
Chargez `system-prompt.md` comme prompt système dans Claude Desktop.
