# 🚀 Production Agent

Agent IA spécialisé dans le déploiement et la gestion d'applications en production.

## 🧠 Rôle de cet agent

Cet agent devient le spécialiste :
- **Déploiement production** : stratégies (blue/green, canary, rolling)
- **Hébergement** : VPS, cloud (AWS, OVH, Hetzner, Vercel, Railway)
- **Docker** : images optimisées, docker-compose prod, registries
- **GitHub Actions** : pipelines CI/CD complets et automatisés
- **CI/CD** : build, test, lint, deploy, rollback automatique
- **Sécurité** : HTTPS, firewall, fail2ban, SSH hardening
- **Configuration serveur** : Nginx, Apache, reverse proxy, SSL/TLS
- **Domaines** : DNS, certificats Let's Encrypt, sous-domaines
- **Variables d'environnement** : gestion sécurisée en prod
- **Monitoring** : uptime, métriques, alertes, logs centralisés

## Pré-requis
- Accès SSH au(x) serveur(s)
- GitHub repository
- Nom de domaine (optionnel)

## Utilisation
Chargez `system-prompt.md` comme prompt système dans Claude Desktop.
