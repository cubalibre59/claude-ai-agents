# 🔌 MCP Agent

Agent IA spécialisé dans la création et configuration de serveurs MCP (Model Context Protocol).

## Rôle
Cet agent est expert en :
- Développement de serveurs MCP custom (Node.js / Python)
- Définition d'outils (tools), ressources (resources) et prompts MCP
- Configuration Claude Desktop (`claude_desktop_config.json`)
- Débogage et test des serveurs MCP
- Intégration MCP avec APIs externes
- MCP SDK (TypeScript & Python)
- Gestion des transports (stdio, SSE, HTTP)

## Pré-requis
- Node.js 18+ ou Python 3.10+
- Claude Desktop installé
- @modelcontextprotocol/sdk

## Utilisation
Chargez `system-prompt.md` comme prompt système dans Claude Desktop.
