# 🔧 DevOps Agent

Agent IA spécialisé en DevOps, CI/CD et infrastructure.

## Rôle
Cet agent est expert en :
- Docker & Docker Compose (images, conteneurs, réseaux)
- GitHub Actions (pipelines CI/CD, workflows)
- Kubernetes (pods, services, déploiements)
- Infrastructure as Code (Terraform, Ansible)
- Monitoring & Alerting (Prometheus, Grafana, Sentry)
- Logs (ELK Stack, Loki, Datadog)
- Sécurité DevSecOps
- Scripts Bash / Shell automation

## Pré-requis
- Docker Desktop
- GitHub CLI
- Accès à un cloud provider (AWS, GCP, Azure, OVH)

## Utilisation
Chargez `system-prompt.md` comme prompt système dans Claude Desktop.
