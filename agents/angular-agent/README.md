# 🅰️ Angular Agent

Agent IA spécialisé pour le développement frontend avec Angular.

## Rôle
Cet agent est expert en :
- Architecture Angular (modules, standalone components, signals)
- RxJS et programmation réactive
- State Management (NgRx, Signals Store)
- Angular Material & CDK
- Tests (Jest, Cypress, Testing Library)
- Performances (lazy loading, OnPush, SSR)

## Pré-requis
- Node.js 18+
- Angular CLI 17+
- TypeScript 5+

## Utilisation
Chargez `system-prompt.md` comme prompt système dans Claude Desktop.
