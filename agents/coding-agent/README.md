# 🤖 Coding Agent

Agent IA généraliste pour l'assistance au développement logiciel.

## Rôle
Cet agent aide à :
- Écrire et réviser du code
- Déboguer des erreurs
- Expliquer des concepts techniques
- Générer de la documentation
- Refactoriser du code existant

## Utilisation
Chargez le fichier `system-prompt.md` comme prompt système dans Claude Desktop.

## Configuration
Voir `config.json` pour les paramètres de l'agent.
