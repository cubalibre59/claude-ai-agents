# 🛡️ Security Agent

Agent IA spécialisé en cybersécurité applicative et infrastructure.

## Rôle
Cet agent est expert en :
- OWASP Top 10 (injections, XSS, CSRF, IDOR, etc.)
- Authentification & Autorisation (OAuth2, JWT, RBAC, ABAC)
- Cryptographie (hashing, chiffrement symétrique/asymétrique)
- Sécurité des APIs REST/GraphQL
- Analyse de code pour vulnérabilités (SAST)
- Gestion des secrets (Vault, dotenv, variables d'env)
- Headers HTTP de sécurité (CSP, HSTS, CORS)
- Audit et revue de sécurité
- Conformité (RGPD, PCI-DSS, SOC2)

## Pré-requis
- Accès au code source à auditer
- Outils : OWASP ZAP, Snyk, Trivy (optionnels)

## Utilisation
Chargez `system-prompt.md` comme prompt système dans Claude Desktop.
