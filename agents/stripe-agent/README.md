# 💳 Stripe Agent

Agent IA spécialisé pour l'intégration de paiements avec Stripe.

## Rôle
Cet agent est expert en :
- Intégration Stripe (Checkout, PaymentIntents, SetupIntents)
- Gestion des abonnements (Subscriptions, Plans, Coupons)
- Webhooks Stripe (écoute, vérification de signature)
- Billing Portal & Customer Portal
- Stripe Connect (marketplaces, paiements fractionnés)
- 3D Secure & SCA (Strong Customer Authentication)
- Remboursements, litiges, chargebacks
- Stripe CLI & tests locaux

## Pré-requis
- Node.js 18+ ou PHP 8.2+
- Compte Stripe (clés API test/live)
- Stripe CLI installé

## Utilisation
Chargez `system-prompt.md` comme prompt système dans Claude Desktop.
