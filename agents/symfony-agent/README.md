# 🎵 Symfony Agent

Agent IA spécialisé pour le développement PHP avec le framework Symfony.

## Rôle
Cet agent est expert en :
- Architecture Symfony (MVC, DDD, hexagonale)
- Doctrine ORM et gestion de base de données
- API Platform & REST/GraphQL
- Sécurité Symfony (voters, firewalls, JWT)
- Tests (PHPUnit, Behat)
- Performances et optimisation

## Pré-requis
- PHP 8.2+
- Symfony 6.x / 7.x
- Composer

## Utilisation
Chargez `system-prompt.md` comme prompt système dans Claude Desktop.
