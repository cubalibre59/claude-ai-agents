# ⚙️ Workflows

Workflows d'automatisation et processus de développement assistés par IA.

## Structure

```
workflows/
├── examples/
│   ├── code-review-workflow.md   # Workflow de revue de code
│   └── deploy-workflow.md        # Workflow de déploiement
└── README.md
```

## Qu'est-ce qu'un workflow ?
Un workflow est une séquence d'étapes que vous suivez avec votre agent Claude
pour accomplir une tâche complexe de manière reproductible.

## Utilisation
1. Ouvrez le workflow correspondant à votre tâche
2. Suivez les étapes dans l'ordre
3. Copiez les prompts suggérés et adaptez-les à votre contexte
